# Flow Field — GitHub Pages prototype

Statische website voor een experimenteel 10-minutenprotocol rond centrale fixatie, perifere visuele aandacht en open awareness.

## Publiceren via GitHub Pages
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `flow-field`.
2. Upload de inhoud van deze map naar de repository.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**.
5. Selecteer **main** en **/(root)**.
6. Klik **Save**.
7. Open het door GitHub gegeven `github.io`-adres.

## Lokaal testen
Open `index.html`, of gebruik VS Code met een eenvoudige lokale webserver.

## Wetenschappelijke beperking
Dit prototype meet geen anatomisch gezichtsveld en is geen medische test. De scores zijn bedoeld voor experimentele zelftracking. Verbetering kan onder meer taakleren weerspiegelen.
